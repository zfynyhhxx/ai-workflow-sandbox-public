# AI Workflow Sandbox Public Constitution

版本：1.0.0；日期：2026-11-12（Asia/Shanghai）。本文件落实用户本轮已明确批准的完整构建范围，不代替后续任务和高风险计划的逐项批准。

## 核心原则

1. **复用现有工具**：CLI/AO/GitHub/Obsidian 各司其职；连接层不取代模型服务或建立平行业务任务数据库。
2. **授权与模型分离**：模型产物不能签发自己的任务批准；Tier 升级不扩大权限或预算。
3. **隔离与保守预算**：真实 Key 只在计量控制面；每次上游请求先预留最大成本，未知用量不退款式归零。
4. **冻结验收与独立审查**：先确认目标测试的真实失败，再进行最小变更；修改验收掩盖失败禁止。Reviewer 不改被审源码，审查绑定 SHA。
5. **人工收口**：服务器必需检查和 PR 流程必须生效；最终合并、发布和知识批准由人执行。

## 运行与知识边界

- 正式和 validation Profile 明确分离；本轮 Claude Code 通过 DeepSeek 的结果不代表 Claude API 已验证。
- 不触碰原私库、业务项目、全局 Codex 规则或既有正式笔记。
- 任务、费用、失败、恢复、原生工具与 CI 的真实证据不可伪造或混写。
